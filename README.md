# Pink Analytica website

Website for Pink Analytica, a business finance and loan advisory practice founded by Keti Bakiri.

## Stack
- Single static file: `index.html` (HTML, CSS, and a small amount of vanilla JavaScript)
- Fonts: IBM Plex Serif, Sans, and Mono via Google Fonts
- No build step and no dependencies

## Design
- Pink palette defined as CSS custom properties, with light and dark themes
- Ticker numbers count up on scroll; sections fade in. Both respect `prefers-reduced-motion`

## Run locally
Open `index.html` in a browser.

## Hosting
Published with GitHub Pages from the `main` branch, root folder.
